Spotify en tu Toyota

Reproducción directa — sin Spotify Developers

Abre Spotify en el Android del TBox, reproduce una canción y vuelve a Rush Launcher. Los botones del panel envían reproducir/pausar y anterior/siguiente a Android.

Para ver el título, artista y avance sin crear una app en Developers, busca en los ajustes de Spotify Device Broadcast Status y actívalo si existe. No todas las versiones ofrecen esta función. Sin ella, la música puede reproducirse normalmente, pero Rush Launcher no tendrá los datos de la canción.

Integración avanzada por Spotify API (opcional)

Solo para cuentas que puedan registrar una aplicación en Spotify for Developers. Permite metadatos, carátula y búsqueda de estado desde Spotify Connect con autorización OAuth PKCE.

No vinculado mediante API

No se solicitan permisos de lectura de notificaciones. El reproductor web puede ofrecer solo fragmentos si el WebView del TBox no admite reproducción cifrada. Configura todo con el vehículo estacionado.

Mi playlist · Spotify

Reproducción a través del reproductor oficial de Spotify. Si no funciona completo en el TBox, pulsa «Abrir mi playlist» para utilizar la aplicación oficial.

Navegación en Rush Launcher

Abre Rush Navigator, escribe una dirección y pulsa Buscar. Selecciona el destino y pulsa Calcular ruta. También puedes pulsar «Elegir en mapa» y tocar un punto. El cálculo necesita conexión a internet y ubicación Android.

Las indicaciones son orientativas: no sustituyen señalización vial ni un sistema GPS fiable. Configura el recorrido antes de conducir.
