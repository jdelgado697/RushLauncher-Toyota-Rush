Luces en la imagen del Toyota Rush

Faros, neblineros y luces traseras se iluminan en el auto virtual. OBD automático exige una señal CAN calibrada; no hay un PID OBD-II estándar de luces.

Esperando datos de luces

CAN rápido: escucha cíclica

Previsualizar efectos (no enciende luces físicas)

En ausencia de señal CAN se utiliza el modo noche como respaldo, identificado.

Calibración CAN por circuito · vehículo estacionado

Conecta ELM327, mantén velocidad ECU en 0 km/h y registra apagadas → encendidas → apagadas → encendidas. La escucha ATMA es pasiva, no escribe comandos en la ECU. Algunas redes Toyota no exponen este dato. Para cada circuito repite OFF/ON/OFF/ON; en intermitentes, mantenlos parpadeando en toda la captura.

Chile sin internet

Se incluyen carreteras y calles de Chile, poblaciones, ríos y áreas verdes desde el extracto OSM/Geofabrik. Si se corta internet el mapa local se activa automáticamente, sin cambiar de visor.

Limitaciones: cartografía simplificada sin imágenes ni edificios descargados. Las búsquedas, rutas nuevas y el tráfico TomTom requieren internet. Datos © OpenStreetMap contributors (ODbL) · Geofabrik.

Rutas y tráfico · navegación avanzada

Con la clave TomTom: rutas que consideran tráfico, hasta dos alternativas y ETA con demora real estimada. Sin clave: OSRM con ETA sin tráfico en tiempo real. Diseño de mapa pastel mantenido.

Requiere TomTom Routing API y conexión. Las consultas y recálculos consumen cuota. Las preferencias no aplican al respaldo OSRM.

«Waze ↗» abre Waze oficial si está instalado. Los reportes comunitarios, controles de velocidad y alertas propias de Waze funcionan únicamente dentro de Waze, no se replican ni simulan.

Cartografía y tráfico TomTom Orbis

Por defecto funciona OpenStreetMap. Para utilizar mapas TomTom y congestión real, agrega tu clave personal de my.tomtom.com. No se incluyen claves ni tráfico simulado. Requiere internet; según tu cuenta puede haber límites y cargos por uso.

Mapa OSM · tráfico desactivado. Introduce una clave para usar TomTom.

El tráfico TomTom superpone flujo vial e incidentes sobre el mapa. Actualiza mosaicos aproximadamente cada tres minutos mientras el tablero esté visible; disponibilidad según cobertura y API. No modifica las rutas ni el tiempo estimado actual. Atribución cartográfica: © TomTom · © OpenStreetMap contributors.

La clave se guarda solo en el almacenamiento local de este Android WebView, y se envía a TomTom por HTTPS al solicitar mosaicos. Para un despliegue público se recomienda usar un proxy seguro y restricciones de clave.

Vista del mapa en Inicio

Rush Drive utiliza un mapa a nivel calle, con más carretera visible por delante del vehículo y una rotación más rápida. El acercamiento se adapta a la velocidad; los botones + y − permiten ajustarlo manualmente.

Puedes elegir la cartografía OpenStreetMap o TomTom. La capa de tráfico requiere una clave API activa. Pulsa ▲ Conduciendo para recuperar el zoom automático después de usar + o −.

Mapa ligero

Mapa único Rush Drive: amplía directamente el mapa del panel, sin crear otro visor ni perder el seguimiento GPS, la ruta o el tráfico TomTom. Al volver, el mismo mapa recupera su lugar. La búsqueda de destinos y las rutas necesitan internet.

Inicio y navegación del TBox

Rush Launcher puede establecerse como Inicio de Android cuando el TBox lo permite. Por seguridad, esta edición no solicita permisos de Accesibilidad y no dibuja controles flotantes sobre Xuper TV.

Dentro de Rush funcionan Inicio, Apps y Atrás. Desde Xuper utiliza el botón Inicio del sistema, si el firmware lo redirige al launcher predeterminado.

Launcher predeterminado del TBox

Rush Launcher puede ser tu pantalla de inicio de Android. Al seleccionar esta opción, Android te permitirá elegirlo si el fabricante del TBox lo autoriza. No modifica el inicio de la radio Toyota ni el sistema del vehículo.

Todavía no se ha seleccionado como inicio predeterminado.

Prueba antes CarPlay, Spotify, el tablero OBD y el botón de restauración. Algunos firmwares Carlinkit bloquean esta elección.

Radio FM de Toyota

El sintonizador de radio FM pertenece a la unidad Toyota. Rush Launcher no puede controlarlo directamente desde el TBox. Para usarlo, vuelve al menú de la radio original.

Spotify en tu Toyota

Reproducción directa — sin Spotify Developers

Abre Spotify en el Android del TBox, reproduce una canción y vuelve a Rush Launcher. Los botones del panel envían reproducir/pausar y anterior/siguiente a Android.

Para ver el título, artista y avance sin crear una app en Developers, busca en los ajustes de Spotify Device Broadcast Status y actívalo si existe. No todas las versiones ofrecen esta función. Sin ella, la música puede reproducirse normalmente, pero Rush Launcher no tendrá los datos de la canción.

Integración avanzada por Spotify API (opcional)

Solo para cuentas que puedan registrar una aplicación en Spotify for Developers. Permite metadatos, carátula y búsqueda de estado desde Spotify Connect con autorización OAuth PKCE.

No vinculado mediante API

No se solicitan permisos de lectura de notificaciones. El reproductor web puede ofrecer solo fragmentos si el WebView del TBox no admite reproducción cifrada. Configura todo con el vehículo estacionado.

Mi playlist · Spotify

Reproducción a través del reproductor oficial de Spotify. Si no funciona completo en el TBox, pulsa «Abrir mi playlist» para utilizar la aplicación oficial.

Navegación en Rush Launcher

Abre el mismo mapa del panel en pantalla completa, escribe tu destino y selecciona una sugerencia. La ruta aparece sobre ese mismo mapa; también puedes mantener pulsado un punto para elegirlo. El cálculo necesita internet y una ubicación GPS actual.

Las indicaciones son orientativas: no sustituyen señalización vial ni un sistema GPS fiable. Configura el recorrido antes de conducir.
